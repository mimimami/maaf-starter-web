MAAF Module

Modulkezelő rendszer lifecycle hookokkal, route/config/migration/asset kezeléssel és CLI generátorokkal.

Funkciók

  • ✅ Modul Regisztráció - Modulok regisztrálása és kezelése
  • ✅ Lifecycle Hookok - Boot, register, activate, deactivate hookok
  • ✅ Route Kezelés - Modulonkénti route kezelés
  • ✅ Config Kezelés - Modulonkénti konfiguráció
  • ✅ Migration Kezelés - Modulonkénti migrációk
  • ✅ Asset Kezelés - Modulonkénti asset-ek (CSS, JS, stb.)
  • ✅ CLI Generátorok - Modul generálás CLI parancsokkal

Telepítés

composer require maaf/module
